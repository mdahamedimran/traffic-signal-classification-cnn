# Independent Test Evaluation

This directory contains the independent test evaluation
results of five trained CNN models using 1,800 previously
unseen traffic light samples.

## Key Results

- Highest test accuracy: 98.89% (EXP03)
- Highest macro F1-score: 94.48% (EXP05)
- Highest macro recall: 98.75% (EXP05)
- Parameter reduction: 90.36% (EXP05)
- Yellow class recall: 100% (EXP05)

All models were evaluated without additional training
or test-based hyperparameter tuning.
